## Hi 👋👋👋

I spent 1 year and 9 months working in network operations monitoring. My job involved checking alerts, logging into routers and switches, investigating device status through CLI and GUI tools, and reporting incidents to customers. I also used Palo Alto Networks' GUI and the AWS Management Console for routine tasks.

I'm now mainly studying programming, Linux, networking, and security. I've also been learning web development because I want to understand how applications work and where security issues can come from.

This account is mostly a place for learning projects and experiments.

## What I'm learning

- **Networking and security:** TCP/IP, Linux, port scanning, packet analysis, and security testing in lab environments.
- **Programming:** Python and JavaScript, mainly through small programs and practical exercises.
- **Web development:** Front-end and back-end basics, APIs, databases, authentication, and common security issues.

I usually work on Linux or Windows and prefer VScode and Neovim, which depends on my mood.
